This establishes successful TFT map rendering followed by a persistent failure; it does not establish the failure's cause or prove the TFT's active source was the installed offline map. Offline POI behavior, GPS quality, voice instructions, camera-alert timing, intercom audio, Bluetooth recovery, and a controlled 30-minute screen-off session still require physical validation unless a newer report records them. Older statements below describe evidence available at the time and are superseded by the report above.

Automated checks and physical-device checks are separate. ### Phase 5: calculate and display a plan (without guidance)

This phase calculates a route only after explicit action and two coordinates. There is no geocoder at this stage: enter destination latitude/longitude. **DEMO Oviedo origin · simulated** uses an invented Oviedo position. **Real GPS origin · latest position** requires an active GPS provider and a fix younger than 15 seconds; start **Start real GPS** or **Start GPS map** and wait for a recent position before calculating. The result identifies the origin used. Do not use the demo for real travel.

For development, use `https://valhalla1.openstreetmap.de/route` only with nonsensitive coordinates, or configure a custom HTTPS endpoint. Calculation sends origin/destination to the selected endpoint, revealing those coordinates and phone IP. The app limits requests to one per second and sends `User-Agent` and `X-Client-Id`. GPS guidance may recalculate after confirmed deviation with at least 30 seconds cooldown; HTTP429 pauses automatic recalculation. The public instance has fair-use conditions and no SLA; read [ROUTING.md](ROUTING.md) before changing service or distributing the app.

1. Select DEMO origin, enter valid destination coordinates, and press **Calculate route · preview**. Missing permission, disabled provider, or a fix older than 15 seconds must request a recent fix without sending another request. The result shows a plan from the fix used for calculation.
3. Press **Cancel calculation** to test cancellation. Calculate successive routes/change destination: late results must not replace later calculations. 4. Check the visible map overlay. The line represents only Valhalla's returned geometry; the marker shows current/demo position, not route progress. Time is a backend estimate. The beta `motorcycle` profile does not certify restrictions or safety for this motorcycle.

### Phase 6: guidance and recalculation

1. At home, calculate a DEMO-origin route and press **Start calculated-route guidance**. The marker must follow the route, update the next maneuver, and reduce remaining distance until arrival. DEMO remains visible and triggers no HTTP recalculation.
2. For GPS, use precise location and a recent fix. Guidance requires finite accuracy up to 25 m; inadequate signal hides turn, distance, and ETA. ETA is approximate, based on Valhalla duration and remaining geometric fraction.
3. Deviation requires at least three distinct positions over five seconds, separated from the route by more than max(40 m, twice accuracy). Recalculation retains the previous route until another valid route arrives. Errors do not replace it; HTTP429 and three failures pause automatic requests. **Recalculate now (GPS)** permits retry while respecting cooldown and Retry-After.
4. **Cancel calculation** also cancels active recalculation and pauses automatic requests. Stopping/changing mode must prevent late responses restoring guidance.

`app/build/outputs/preview/guidance.png` is exported with Android Canvas in Robolectric: it checks HUD composition on a drawn test base, not MapLibre GPU rendering. At this stage physical guidance, deviation, recalculation, GPS, and screen-off tests remained pending. Thresholds were not road-calibrated; geometric limits are documented in [ROUTING.md](ROUTING.md).

### Phase 7: explicit destination search

Search starts only after **Search**; typing issues no requests at this stage. Enter a name/address with city, check the HTTPS endpoint, and press Search. Use only nonsensitive queries on the public service: the provider receives text and source IP. The UI explains GPS is not sent; avoid personal/confidential data. No autocomplete or result fetching occurs while typing. Settings can change the Nominatim-compatible endpoint without updating the app.

1. Start with a synthetic nonprivate query, such as a known public site, and confirm full name and OSM/license attribution. No results is not an error. Changing text/endpoint while searching must cancel the previous request and remove its buttons; a late response must not replace the new query.
2. Press **Cancel search** during a query; the connection must close with no selectable result remaining. Repeat an identical query to check memory caching, including empty responses; change endpoint/language/parameter to verify entries do not mix. Cache and rate limiter exist only in process memory (100 entries/24 hours); no history is persisted.
3. Selecting a result fills the destination and starts preview calculation without guidance: no active maneuvers appear before **Start**. Editing the query clears the old destination; Calculate without a current selection must not reuse earlier coordinates. With guidance active, choosing/calculating another result preserves existing guidance while waiting or after failure. A new plan does not replace guidance until **Start**. **Stop route** explicitly removes the active route. The first result is not selected automatically.
4. Do not stress-test the public service. OSMF limits all installations of this app together to an absolute maximum of one request per second. The adapter serializes requests, caches queries, identifies the app with User-Agent, and honors Retry-After on 429; a 429 blocks new searches until the period expires and requires manual action without a retry loop. Controlled-server adapter tests cover cancellation, query encoding, caching, and 429; do not generate automatic test traffic to public Nominatim.

Search provides place candidates, not validated addresses or motorcycle access. The user confirms the result/calculation; Valhalla may snap it to a nearby road. At this phase search/routes and guidance had not been tested on phone/TFT or while riding. See [GEOCODING.md](GEOCODING.md) and the [official Nominatim policy](https://operations.osmfoundation.org/policies/nominatim/).
